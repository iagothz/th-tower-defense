# Decisões de arquitetura (ADRs)

Cada ADR registra uma decisão que molda o projeto: o contexto, o que foi decidido e o que isso custa. Um ADR
aceito não é editado. Para mudar a decisão, escreva um novo ADR que o substitua e marque o antigo como
"Substituído por ADR-NNNN".

| ADR | Decisão | Status |

| [0001](0001-libgdx-com-kotlin.md) | libGDX com Kotlin, multi-módulo | Aceito |
| [0002](0002-camadas-logic-app-ui.md) | Camadas `logic`, `app` e `ui` | Aceito |
| [0003](0003-save-em-texto.md) | Save em texto sobre `Preferences` | Aceito |
| [0004](0004-arte-renderizada-no-blender.md) | Arte dos dados renderizada no Blender | Aceito |
| [0005](0005-chave-de-release-fora-do-git.md) | Chave de release fora do git | Aceito |

Modelo para um ADR novo: `NNNN-titulo-curto.md`, com as seções Status, Contexto, Decisão e Consequências.
